Installation & Setup

Install JaBoard from a signed APK, then grant only the permissions for the features you want. Every permission except the first is optional.

Step by step

Install the APK

Download the signed APK

Open the GitHub Releases page and download the APK attached to the Latest Release, using your phone's browser or transferring the file from a computer.

Allow installs from your browser or file manager

Android blocks sideloaded apps by default. When prompted, open the settings screen and enable Install unknown apps for the app you used to open the file.

The exact menu name varies by manufacturer. It is usually found under Settings > Apps > Special app access. You can turn the permission off again after installing.

Install and open JaBoard

Tap the downloaded APK, confirm the install, and launch the app. On first launch you can choose a layout preset in Bento Studio and decide which optional permissions to grant. You can change them at any time in Android Settings.

Permissions

What JaBoard asks for, and why

Select a permission name to copy it. Every request is tied to a specific feature.

Notification Access

Required for media BIND_NOTIFICATION_LISTENER_SERVICE

Android only lets an app read other apps' media sessions through a notification listener. Enabling JaBoard here unlocks cross-app playback controls and the synced lyrics viewer.

How to enable
  1. Open JaBoard and tap the prompt for media access, or go to Android Settings and search for Notification access.
  2. Select JaBoard in the list.
  3. Turn the toggle on and confirm the system warning.
Unlocks
MediaSession controls and live time-synced lyrics.
If denied
The rest of the app works normally. Only the media card and lyrics are unavailable.

Coarse Location

Optional ACCESS_COARSE_LOCATION

Used only to find your approximate area for weather. If you prefer not to share location, search for a city by name through Open-Meteo instead.

Option A
Grant coarse location to use one-tap GPS lookup.
Option B
Decline, then search and pick a city manually in the weather settings.
If denied
Weather still works through manual city search.

Calendar

Optional READ_CALENDAR

Lets the Calendar card show your upcoming events. JaBoard only reads events; it does not edit them.

Unlocks
Upcoming events on the dashboard.
If denied
The Calendar utility still shows dates, without event details.

Notifications

Optional POST_NOTIFICATIONS

Allows the Countdown Timer to alert you when it finishes. On recent Android versions this is a runtime permission you grant explicitly.

Unlocks
Countdown timer alerts.
If denied
Timers still run, but you will not get a notification when one ends.

Known limitations

Honest hardware reporting

JaBoard reports values that Android's public APIs actually return: battery state from BatteryManager, memory from ActivityManager.MemoryInfo, storage from StatFs, and SoC details from platform metadata.

Per-core CPU usage percentages are not shown. They would require reading /proc/stat, which modern Android restricts for regular apps. Rather than estimate or fabricate a number, JaBoard leaves that metric out.

Some Wi-Fi details and manufacturer-specific fields may also vary by device and Android version.
